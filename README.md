# Teeru Hairstyle Catalogue
React + Vite starter for Men, Women and Kids.

- Men: 89 styles
- Women: 110 styles
- Kids: 90 styles

Run locally: `npm install` then `npm run dev`. Build: `npm run build`.

Hairstyle cards use remote Unsplash demo portraits, not verified photos of the exact haircut and not guaranteed to be Indian models. Replace with licensed Indian model images matching each style before production. The hero artwork is an AI-generated concept mockup featuring Indian demo models.

AI transformation, photo upload, salon listings, live booking, login and payments are not connected; these require backend/API integration.

For GitHub Pages project URLs, change `base: '/'` in vite.config.js to `base: '/YOUR-REPOSITORY/'`. Cloudflare Pages build command: `npm run build`; output: `dist`.
